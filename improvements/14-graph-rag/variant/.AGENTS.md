# Каталог: variant/

## Назначение
Вариант агента Baseline Agent с Graph-RAG: in-memory граф HR/policy и локальный tool `graph_query`.

## Файлы

### graph_rag.py
**Классы и функции:**
- `KnowledgeGraph` — dict-based граф (узлы + рёбра)
  - `neighbors()`, `find_nodes()`, `traverse()` — обход и поиск
  - `employee_ids_in_department()`, `employees_with_active_policy()` — HR/policy join
- `GraphQueryEngine` — исполнение domain-specific запросов
- `build_demo_graph()` — демо-данные POC
- `create_graph_tools()` — LangChain tool `graph_query`
- `is_empty_result()` — детектор пустого результата для NTA-style отказа
- `run_graph_query()` — helper для тестов и CLI

### agent_core.py
- `load_local_tools()` — подключает `graph_query` при `graph_rag.enabled: true`
- `AgentResources.create()` — объединяет local + MCP tools

### prompts/system_master.txt
Правила Graph-RAG: агрегаты только через `graph_query`, пустой граф → честный отказ.

### config.yml
```yaml
graph_rag:
  enabled: true
```

## Зависимости
- `langchain_core` — StructuredTool
- MCP tools (опционально) — для простых lookup, не для агрегатов
