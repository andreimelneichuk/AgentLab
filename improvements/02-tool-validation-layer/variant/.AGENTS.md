# Каталог: variant/

## Назначение

Изолированная копия Basic-агента с валидационным слоем (02) перед вызовом MCP-инструментов.

## Файлы

### agent_core.py
**Классы:**
- `AgentResources` — ресурсы агента, включая `tool_validator`
- `BasicLoopSession` — цикл LLM → validate → tool → LLM с retry/STOP
- `TurnResult` — результат хода, поля `validation_rejections`, `stopped_reason`

**Функции:**
- `validation_limits(config)` — читает `tools.validation.max_retries`

### tool_validator.py
**Классы:**
- `ToolValidator` — реестр схем и trace отказов (валидация в `tool_executor`)
- `ValidationResult`, `ValidationRejection` — результат и trace отказа

**Функции:**
- `extract_json_schema(tool)` — алиас `extract_input_schema` из `tool_executor`
- `format_validation_errors()` — feedback для LLM
- `validation_stop_message()` — сообщение при STOP

### tool_executor.py
**Функции (strict mode для 02):**
- `execute_tool_command(..., strict=True)` — единый путь валидации
- `SCHEMA_AUGMENTATIONS`, `validate_arguments_strict()`

### tests/test_tool_validation.py
Unit-тесты валидатора и интеграции с `_execute_tools` / retry loop.

## Зависимости

- `benchmark/mcp_tool_registry.py` — имена mock-инструментов (схемы из MCP runtime)
- `langchain_mcp_adapters` — загрузка tools с `inputSchema`
