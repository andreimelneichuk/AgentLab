# Каталог: rules/

## Назначение

Policy-as-code: бизнес-правила Baseline Agent по доменам (policy, CRM, HR). Версионируются отдельно от системного промпта.

## Файлы

### policy.yaml
- `deny_decoy_tools` — запрет всех `decoy_*`
- `policy_ok_requires_fact` — `[POLICY_OK]` только после `get_policy_fact`
- `no_false_success_after_tool_error` — запрет ложного успеха

### crm.yaml
- `crm_batch_limit` — не более 3 CRM-вызовов за ход
- `company_before_contact` — `customer_get` перед `ticket_create` (aliases: fetch_company/fetch_contact)
- `customer_before_quote` — `customer_get` перед `sales_quote`
- post-tool проверки полей `customer_get`, `ticket_create`

### hr.yaml
- `employee_before_leave` — `employee_lookup` перед `leave_balance`
- `hr_two_phase_leave` / `hr_two_phase_org` — двухфазное подтверждение HR
- post-tool проверки полей `employee_lookup`, `leave_balance`

## Зависимости

- `guardrails.py` — загрузка и исполнение правил
- `agent_core.py` — вызов хуков pre/post tool и post response
