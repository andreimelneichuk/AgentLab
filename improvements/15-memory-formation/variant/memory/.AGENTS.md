# Каталог: memory/

## Назначение

Модуль **Memory Formation** (Mem0-style): извлечение дискретных фактов из диалога,
дедупликация (UPDATE не ADD), семантический recall и инжекция в контекст агента.

## Файлы

### models.py
- `ExtractedFact` — факт до записи в store
- `MemoryFact` — каноническая запись с TTL и embedding

### policy.py
- Разрешённые типы: `preference`, `entity_id`, `decision`
- `NEVER_STORE_PATTERNS` — tool XML, ошибки
- TTL по типам (`policy` — 1ч, `entity_id` — 30д)

### extractor.py
- `FactExtractor` — rule-based + опциональный LLM
- Паттерны для предпочтений, entity IDs, решений по tool

### dedup.py
- `find_duplicate()` — совпадение по key или семантической близости

### retriever.py
- `retrieve_top_k()` — keyword + hash-embedding cosine
- `simple_embedding()` — без внешних vector DB

### store.py
- `SqliteMemoryStore` — SQLite, scope по `user_id`

### manager.py
- `MemoryManager` — ingest, retrieve, `build_augmented_system_prompt()`

## Зависимости

- `agent_core.BasicLoopSession` — вызывает manager до/после turn
- `config.yml` → секция `memory`
