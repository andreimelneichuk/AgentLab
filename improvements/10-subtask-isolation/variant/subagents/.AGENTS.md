# Каталог: subagents/

## Назначение
Доменные субагенты с урезанным набором MCP tools и structured JSON handoff.

## Файлы

### handoff.py
- `SubtaskHandoff` — контракт между субагентами (`subtask`, `status`, `data`, `tools_used`, `errors`)

### domain_tools.py
- `DOMAIN_TOOL_NAMES` — границы tools по 4 MCP mount
- `filter_tools_for_domain()` — фильтрация tools
- `infer_domain` helpers: `domain_for_tool()`, `TOOL_TO_DOMAIN`

### factory.py
- `SubagentFactory` — `resources_for()`, `spawn_session()`, `spawn_recall_session()`

### prompts.py
- `domain_system_prompt()` — узкий system prompt per domain

## Зависимости
- `agent_core.py` — `AgentResources`, `BasicLoopSession`
