# Каталог: prompts/

## Назначение
Шаблоны системных промптов агента Basic.

## Файлы

### system_master.txt
Jinja2-шаблон системного промпта в **4 секциях** (строгий порядок):
1. Роль и область действия (включая негативную)
2. Инструменты со схемами и «НЕ использовать когда»
3. Правила принятия решений (STOP при ошибке)
4. Формат вывода

Переменные шаблона задаются в `agent_core._prompt_template_variables()`.
Для бенчмарка (`is_default_bot=False`) Секция 2 заполняется динамически через `prompt_tools.render_benchmark_tools_section()` из `benchmark/mcp_tool_registry.py` (canonical tools only; decoy упоминаются только в строках «НЕ использовать»).

## Зависимости
- `agent_core.render_system_prompt()` — рендер шаблона
- `agent_core.messages_to_langchain()` — передача промпта в LLM как SystemMessage
- `prompt_tools.py` — генерация `tools_section` для бенчмарка
