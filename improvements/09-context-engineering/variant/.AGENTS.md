# Каталог: variant/

## Назначение
Вариант агента Baseline Agent с контекстной инженерией (Write / Select / Compress / Isolate).

## Файлы

### agent_core.py
**Классы:**
- `AgentResources` — ресурсы агента + `scratch_store`, `context_policy`
- `BasicLoopSession` — цикл LLM→tool; `_prepare_llm_messages()` перед invoke
  - `last_context_report`  — отчёт сегментов prompt

### context_policy.py
**Классы:**
- `ContextPolicyConfig` — настройки из `config.yml` → `context_engineering`
- `ContextPolicy` — pipeline Write → Select → Compress → Isolate
  - `prepare_for_llm()` — подготовка messages перед LLM
  - `write_large_tool_results()` — Write
  - `select_relevant_history()` — Select
  - `compress_mask_old_tools()` — Compress (masking)
  - `isolate_message_blocks()` — Isolate

### scratch_store.py
**Классы:**
- `ScratchStore` — in-memory scratch pad
  - `save()`, `load()`, `make_key()`
- `estimate_tokens()` — оценка размера текста

## Зависимости
- `config.yml` — секция `context_engineering`
- `prompts/system_master.txt` — system rules (блок RULES при isolate)
