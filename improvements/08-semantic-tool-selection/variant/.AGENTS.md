# Каталог: variant/

## Назначение

Вариант AI-агент с семантической фильтрацией инструментов перед каждым user turn.

## Файлы

### tool_retriever.py
**Классы и функции:**
- `TfidfToolRetriever` — TF-IDF индекс + top-k cosine search
- `ToolSelectionConfig` — настройки top_k, mandatory, deny, enabled
- `select_tool_names()` — семантический отбор с mandatory/deny/decoy
- `filter_openai_tools()` — фильтрация OpenAI tool dicts
- `build_query_text()` — текст запроса из user message + history

### agent_core.py
**Изменения:**
- `AgentResources.tool_retriever` — retriever при создании ресурсов
- `AgentResources.select_openai_tools_for_turn()` — фильтр перед bind_tools
- `BasicLoopSession.run_turn()` — использует отфильтрованный набор tools

### config.yml
- Секция `tool_selection` — параметры retriever

## Зависимости
- `benchmark/mcp_tool_registry.py` — тексты описаний для тестов corpus
