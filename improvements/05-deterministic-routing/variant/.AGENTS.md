# Каталог: variant/

## Назначение
Вариант AI-агент с детерминированным rule-based routing инструментов по доменам MCP.

## Файлы

### routing.py
**Функции:**
- `route_user_message(message)` — intent → domain → allowed_tools + prompt fragment
- `filter_tools_by_route(tools, route)` — фильтрация BaseTool для LLM
- `is_tool_allowed(tool_name, route)` — guard при исполнении tool

**Константы:** `CORE_TOOLS`, `HR_TOOLS`, `CRM_TOOLS`, `SSE_TOOLS`, `POLICY_TOOLS`, `DECOY_TOOLS`

### agent_core.py
**Классы:**
- `AgentResources` — загрузка всех MCP tools при старте
- `BasicLoopSession` — per-turn routing в `run_turn()`, фильтрация `bind_tools`

### tests/test_routing.py
Unit-тесты маршрутизации на фразах из `s08_multiserver.yaml`.

## Зависимости
- `benchmark/mcp_tool_registry.py` — группировка tools по серверам (концептуально)
